## Roadmap

SharaSpace lends a room by the hour. A slot names a day and the hours it runs, the diary refuses a clash, and a booking keeps the rate the room carried when the booker took it. The hand-written runner carries 18 checks.

1. Add a booking calendar so a booker can see the free hours of a day before choosing.
2. Add rate rules per hour of the day, so a host can price an evening slot above a morning one.
3. Add a waiting list for a day, so a booker hears when a slot frees.
4. Add a host view of takings per room and per month.
5. Expand the hand-written runner to cover overlapping slots across a day boundary, a room that closes mid diary, and a cancelled booking that returns its rate to the takings.
